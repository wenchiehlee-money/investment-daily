# Daily Summaries

Store generated daily investment summaries here using this path convention:

```text
summaries/YYYY/MM/YYYY-MM-DD.md
```

Example:

```text
summaries/2026/09/2026-09-05.md
```

## Rules

- One file per calendar date in `Asia/Taipei`.
- Use the structure in `templates/daily-summary-template.md`.
- Prefer updating the same day's file when new material information appears rather than creating multiple versions.
- Keep factual claims sourced and distinguish facts from analysis.
- Preserve historical files; later corrections should be clearly noted rather than silently rewriting material historical conclusions when possible.
